# HÉLIXSTRAT — site vitrine

Site d'une page en HTML/CSS/JS simple, publié automatiquement par Vercel à chaque envoi sur `main`.

- `index.html` : la page (accès par code + contenu)
- `css/style.css` : couleurs, polices, mise en page
- `js/main.js` : page d'accès par code
- `fonts/` : Rozha One, Roboto, Walkway (format web .woff2)
- `img/` : logo, hélice, icônes
